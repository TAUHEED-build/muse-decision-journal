MUSE — AI Decision Journal

> Think clearly. Challenge your assumptions. Learn from your decisions.

MUSE is a minimalist AI decision journal designed to help people think through important decisions instead of simply telling them what they want to hear.

It acts as an intellectual sparring partner — questioning assumptions, presenting counterarguments, separating facts from beliefs, and highlighting uncertainty before you make a decision.

Why MUSE?

Most AI assistants are optimized to give answers.

MUSE is designed to help you think better.

Instead of:

> "Yes, that's a good idea."

MUSE asks:

- What assumptions are you making?
- What evidence supports them?
- What could you be overlooking?
- What would the strongest counterargument be?
- What information would change your decision?
- How confident are you, and why?

The final decision always remains with the user.

Core Features

- 🧠 AI Decision Analysis — Break down a decision and examine it from multiple perspectives.
- ⚔️ Assumption Challenges — Identify assumptions that may be influencing your thinking.
- 🔄 Counterarguments — Explore the strongest opposing viewpoints.
- 📊 Decision History — Keep track of previous decisions and reasoning.
- 🎯 Outcome Reviews — Revisit decisions later and compare expectations with what actually happened.
- 💡 Insights — Learn patterns from your previous decisions.
- 💾 Local Persistence — Keep decision data available across sessions.
- 📱 Responsive UI — Designed to work across desktop and mobile screens.

Product Philosophy

MUSE is built around a simple principle:

AI should not replace your judgment. It should improve it.

The goal isn't to predict the perfect decision or pretend to know the future.

The goal is to make your reasoning clearer, expose blind spots, and help you make more informed choices.

Getting Started

1. Clone the repository

git clone YOUR_GITHUB_REPO_URL
cd muse-ai

2. Install dependencies

npm install

3. Configure environment variables

Create a ".env" file and add the required API configuration:

GEMINI_API_KEY=your_api_key_here

Never commit your API key or other secrets to GitHub.

4. Start the development server

npm run dev

Then open the local URL shown by Vite.

Build for Production

npm run build

To check the TypeScript code:

npm run lint
